# Eternity Customz Website

A lightweight static website built with plain HTML, CSS, and JavaScript.

## Structure

```
.
├── index.html            # Home page
├── about.html            # About page
├── services.html         # Services page
├── contact.html          # Contact page with form
├── css/
│   └── styles.css        # Global styles and design tokens
├── js/
│   └── main.js           # Shared behavior (nav toggle, form, footer year)
│   └── services-data.js  # Shared services behavior
│   └── vehicles-data.js  # Shared vehicles behavior
└── images/               # Images and other static files
```
